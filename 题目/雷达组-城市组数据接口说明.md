**文档版本**：v1.0
**编制**：雷达探测建模组
**对接方**：3D 城市建模任务小组
**日期**：2026-10-14

## 1. 目的

本说明用于明确雷达探测建模组（以下简称"雷达组"）对 3D 城市建模任务小组（以下简称"城市组"）源数据的**调用方式、处理流程、接口格式及质量要求**，作为双方数据对接的技术契约。

## 2. 我们需要什么数据

### 2.1 必需数据（遮挡计算核心）

| 数据 | 路径（相对项目根目录） | 用途 | 优先级 |
|---|---|---|---|
| 建筑轮廓矢量 | `区域数据/building/zheng_apart.shp` | 建筑遮挡 LOS 判定、遮蔽角计算 | **P0** |

## 3. 我们如何使用数据

### 3.1 数据流

```
城市组源数据                          雷达组处理                          雷达组输出
─────────────────────────────────────────────────────────────────────────────────
building/zheng_apart.shp  ──→  坐标转换(EPSG:3857→ENU)  ──→  buildings_enu.mat
dem/dem.tif               ──→  重采样+插值(30m→连续)    ──→  dem_enu.mat
                              ↓
                        空间索引建立(50m栅格)  ──→  building_grid.mat
                              ↓
                        LOS查询/遮蔽角计算/刀锋衍射  ──→  雷达覆盖热力图
```

### 3.2 坐标系约定

| 项目 | 约定 |
|---|---|
| **计算坐标系** | 本地 ENU（东-北-天），单位：米 |
| **ENU 原点** | AOI 中心：东经 113.662169°，北纬 34.788899°（与 `tileset.json` 的 ENU→ECEF 变换原点一致） |
| **高程基准** | 正常高（1985 国家高程基准），与 DEM 一致；白模椭球高需 +4.41 m 校正 |
| **坐标转换责任方** | **雷达组自行完成**，城市组无需额外处理 |

## 4. 数据质量问题及应对

基于城市组《源数据技术报告》第 6 节，以下问题直接影响雷达建模，已制定应对策略：

| # | 问题 | 对雷达建模的影响 | 雷达组应对 |
|---|---|---|---|
| 1 | `building` 元数据字段过期（`HEIGHT` vs 实际 `high`） | 代码读取错误 | 以 DBF 实测字段 `high` 为准 |
| 2 | DEM 35.8% NoData、影像 35.2% NoData | 边界区域高程缺失 | 掩膜 `-9999`/`255`，边界外推或标记为未知 |
| 3 | DEM 正常高 vs 白模椭球高（+4.41 m） | 三维场景垂直偏移 | 计算用 DEM 正常高，展示时校正白模 |
| 4 | **白模高度与 `high` 严重不符**（塔楼偏差极大） | **遮挡计算若用白模将完全失真** | **仅用 building 矢量 `high` 字段做遮挡计算，白模仅用于可视化** |
| 5 | `CLASS` 32 类无码表 | 无法做建筑类型相关分析 | 暂不利用，如需语义信息另索码表 |
| 6 | `tileset.json` 的 `high.min/max` 为哨兵值 | 误用导致荒谬结果 | 忽略该字段 |
| 7 | 一栋建筑多面片（如河南博物院 4 片） | 按记录数统计栋数偏多 | 按 `NAME`/`CARTO_ID` 聚合，或直接使用面片（对遮挡计算无影响） |

## 5. 接口契约

### 5.1 城市组 → 雷达组（数据提供）

**无需城市组额外工作**，源数据已满足要求。仅需确认：

| 确认项 | 内容 |
|---|---|
| 数据路径 | 源数据是否位于 `d:\myproject\radar\区域数据\` 或其子目录？ |
| 数据版本 | 是否为最终版？后续是否有更新（如新增建筑、修正高度）？ |
| 坐标基准 | 是否同意以 AOI 中心 (113.662169°E, 34.788899°N) 作为统一 ENU 原点？ |

### 5.2 雷达组 → 城市组（处理结果共享）

雷达组完成数据预处理后，将向城市组共享以下中间成果，供复核及演示使用：

| 文件 | 格式 | 内容 | 共享时间 |
|---|---|---|---|
| `buildings_enu.mat` | MAT | 建筑轮廓 ENU 坐标 + 高度 + 原始属性 | D1 完成后 |
| `dem_enu.mat` | MAT | DEM ENU 网格 + 高程插值函数 | D1 完成后 |
| `building_grid.mat` | MAT | 50m 栅格建筑索引（加速查询） | D1 完成后 |
| 坐标转换脚本 | `.m` | EPSG:3857→ENU 转换代码（供复核） | D1 完成后 |

### 5.3 联合查询接口（供部署优化调用）

以下为雷达组将实现的 MATLAB 函数签名，城市组如需在三维场景中叠加雷达覆盖显示，可直接调用：

```matlab
%% 建筑遮挡查询
% 判断雷达-目标视线是否被建筑遮挡
%   radar_pos_enu: [x, y, z] 雷达位置 (m, ENU)
%   target_pos_enu: [x, y, z] 目标位置 (m, ENU)
%   buildings: 建筑结构体 (由 buildings_enu.mat 加载)
%   返回: true=可见, false=被遮挡
visible = query_los(radar_pos_enu, target_pos_enu, buildings);

%% 遮蔽角查询
% 计算雷达在指定方位上的最大建筑遮蔽角
%   radar_pos_enu: [x, y, z] 雷达位置 (m, ENU)
%   azimuth_deg: 方位角 (度, 0=北, 顺时针)
%   返回: 最大遮蔽角 (度, 0=无遮挡)
mask_angle = query_mask(radar_pos_enu, azimuth_deg, buildings);

%% 刀锋衍射损耗
% 被遮挡时的绕射损耗估算 (ITU-R P.526)
%   radar_pos_enu / target_pos_enu: 位置 (m, ENU)
%   buildings: 建筑结构体
%   freq_hz: 雷达工作频率 (Hz)
%   返回: 衍射损耗 (dB), 0=无遮挡
L_diff = diffraction_loss_db(radar_pos_enu, target_pos_enu, buildings, freq_hz);
```

## 6. 对城市组的可选请求

以下非必需，但若提供可提升成果质量：

| 请求 | 优先级 | 说明 |
|---|---|---|
| `CLASS` 分类码表 | 低 | 用于建筑类型相关的损耗精细化（如玻璃幕墙反射差异） |
| 影像时相/传感器信息 | 低 | 报告插图注明数据来源 |
| 建筑高度置信度标注 | 中 | 区分实测高度与估算高度，用于不确定性分析 |
| 白模高度修正版 | 低 | 若后续修复白模高度，可更新可视化效果 |
